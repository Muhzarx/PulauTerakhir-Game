PULAU TERAKHIR

Kapalmu karam. Kamu terbangun sendirian di sebuah pulau yang tidak dikenal. Kumpulkan sumber daya, jaga kebutuhanmu, dan bangun api unggun sebelum malam tiba.

Kontrol: gunakan joystick di kiri bawah. Tekan AMBIL di dekat sumber daya. Di komputer gunakan WASD dan tombol E.

MEJA CRAFTING

Gunakan sumber daya yang kamu kumpulkan.

🔥 Api unggun
5 kayu + 2 batu
🪓 Kapak sederhana
3 kayu + 2 batu
